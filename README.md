# EasyPoisons

Plan a batch of rogue poisons and buy the missing reagents at the vendor in one
click. For World of Warcraft 1.12.1. Requires
[ClassicAPI](https://github.com/brues-code/ClassicAPI).

## Install

Download `EasyPoisons.zip` from the [latest release](https://github.com/Fostercare5988/EasyPoisons/releases/latest), extract it into
`Interface\AddOns` and restart the game.

## Use

1. Open a poison vendor. The window appears beside the vendor window.
2. Choose how many of each poison you want.
3. Press **Buy**. Only what your bags don't already hold is bought.

`/ep` opens or closes the window at any vendor. You can also switch on
"Keep 20 Flash Powder" in the window.
